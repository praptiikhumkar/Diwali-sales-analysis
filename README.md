# Diwali Sales Analysis - Exploratory Data Analysis (EDA)

## Project Overview
This project involves a comprehensive analysis of retail sales data during the Diwali festival period. Using Python and data visualization libraries, the analysis identifies key customer demographics and purchasing patterns to help a business improve its marketing strategy and inventory management.

## Key Objectives
* Identify the primary consumer segments (Gender, Age, Location).
* Analyze which product categories have the highest demand.
* Determine the geographical regions contributing most to the revenue.

## Technologies Used
* **Language:** Python
* **Libraries:** Pandas (Data Manipulation), NumPy (Numerical Analysis), Matplotlib & Seaborn (Data Visualization)
* **Environment:** Jupyter Notebook

## Data Cleaning & Preparation
* Dropped unrelated and empty columns to optimize the dataset.
* Handled null values in the 'Amount' column to ensure calculation accuracy.
* Converted data types for efficient processing.

## Key Insights from Analysis
* **Gender:** The majority of buyers are females, and they have higher purchasing power than males.
* **Age Group:** Customers aged 26-35 years are the most active segment.
* **State:** Uttar Pradesh, Maharashtra, and Karnataka are the top three states in terms of both orders and total sales amount.
* **Marital Status:** Married women are the most frequent shoppers.
* **Occupation:** Professionals in the IT Sector, Healthcare, and Aviation are the top spenders.
* **Product Category:** Food, Clothing, and Electronics are the top-selling categories.

## Conclusion
To maximize revenue, marketing efforts should be focused on married women aged 26-35 living in major states like Uttar Pradesh and Maharashtra, specifically targeting those working in the IT and Healthcare sectors.

## How to Run the Project
1. Clone this repository.
2. Ensure you have Python and the required libraries installed: `pip install pandas matplotlib seaborn`.
3. Open the `Diwali sales analysis.ipynb` file in Jupyter Notebook or VS Code.
